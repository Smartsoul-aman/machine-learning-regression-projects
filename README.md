## 📌 About This Project

Welcome to my **Machine Learning Regression Practice Repository!**

This repository contains hands-on implementations of three important regression algorithms using Python and Scikit-learn.

The main objective of this project is to understand how different regression algorithms work, train predictive models, evaluate their performance, and visualize actual vs predicted results using real-world-inspired datasets.

## 🎯 Algorithms Implemented

### 1. Simple Linear Regression
- Dataset: Study Hours vs Exam Scores
- Input Feature: `StudyHours`
- Target Variable: `ExamScore`
- Built and trained a Linear Regression model.
- Calculated slope and intercept.
- Performed predictions and visualized the regression line.

### 2. Multiple Linear Regression
- Dataset: Car Price Prediction
- Input Features:
  - `EngineSize_L`
  - `Mileage_km`
  - `CarAge_years`
- Target Variable: `Price_USD`
- Trained a Multiple Linear Regression model.
- Analyzed coefficients and intercept.
- Evaluated predictions using regression metrics.

### 3. Gradient Boosting Regressor
- Dataset: Laptop Price Prediction
- Input Features:
  - `RAM_GB`
  - `Storage_GB`
  - `ScreenSize_inch`
  - `Weight_kg`
  - `BatteryLife_hrs`
- Target Variable: `Price_USD`
- Implemented Gradient Boosting Regressor.
- Analyzed feature importance.
- Compared actual and predicted prices.

- **RMSE:** Root Mean Squared Error
- **R² Score:** Coefficient of Determination
